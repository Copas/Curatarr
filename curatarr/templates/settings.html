Curatarr plugin for Jellyfin

With the plugin, Delete in any Jellyfin app marks a film or show Leaving Soon instead of deleting its files, so it leaves through Radarr or Sonarr and can still be saved; deleting it again deletes it now. Jellyfin's web app gets a Leaving Soon menu item beside Delete, which there deletes straight away (with the File Transformation plugin). Episodes, seasons and anything Curatarr doesn't manage are deleted by Jellyfin as usual. One click installs it in Jellyfin and sets it up; there's nothing to copy.

Compression first

If an external transcoder (Tdarr, Unmanic, FileFlows) saves space by recompressing, Curatarr can wait for it: while it has files queued, being low on space marks nothing Leaving Soon. Below the critical threshold, cleanup goes ahead anyway. The transcoder, or a small script beside it, sends how many files are waiting to POST {{ request.host_url.rstrip('/') }}/api/v1/compression ({"pending": 312, "source": "Tdarr"}, with the webhook token in X-Curatarr-Token), or keeps a file in place while it has work.
