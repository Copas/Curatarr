Jellyfin webhook

The webhook tells Curatarr about playback, finished episodes, and favorites as they happen. Without it, Curatarr still catches up at each hourly reconciliation. Token status: {{ 'configured' if webhook_present else 'not configured' }}. The token is shown only once; if you did not copy it, leave the box below empty and click Save or generate token to make a new one.

Set up the Jellyfin Webhook plugin
  1. In Jellyfin: Dashboard → Plugins → Catalog, install Webhook if needed, then restart Jellyfin.
  2. Dashboard → Plugins → Webhook → Add Generic Destination.
  3. Webhook Name: Curatarr. Webhook Url: {{ request.host_url }}api/v1/webhook/jellyfin
  4. Notification Type: tick Playback Start, Playback Stop, and User Data Saved. Leave Playback Progress off.
  5. Item Type: tick Movies, Episodes, and Series. Leave the user filter empty so every user counts.
  6. Leave Send All Properties unticked and paste this into Template: 
    {{ webhook_template }}
  7. Under Headers, add Key X-Curatarr-Token with the webhook token as its Value, then Save.
