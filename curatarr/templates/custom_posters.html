Custom posters

Pictures chosen for titles instead of Jellyfin's own poster. Upload one on a title's page, or drop pictures in an import folder. The poster each one replaced is kept, so it can be restored.

Import folder

Every couple of minutes Curatarr looks here for new pictures (JPEG, PNG or WebP) and puts each on the title its name matches: The Big Lebowski (1998).jpg, the-big-lebowski-1998.png or 08_the-big-lebowski.jpg. The year is needed only when titles share a name. A file saved again later replaces its poster. The folder must be readable by Curatarr's worker.

Make them with an AI

Curatarr writes the prompts; an image-making AI agent (Codex, or any other that can read and save files) makes the posters and saves them in the import folder, where Curatarr puts them on. Each prompt is a batch, with each title's year, genres, plot and the file name to save it as.

{% if not folder %} Set the import folder above first, so the prompts say where to save.{% endif %}

Only use photos of people who've agreed. The photos are read by the AI agent you paste the prompt into, never by Curatarr; if it's a cloud service, they're sent there.
