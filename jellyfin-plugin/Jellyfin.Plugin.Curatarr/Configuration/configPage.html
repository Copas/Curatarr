Curatarr

With this plugin, Delete in any Jellyfin app asks Curatarr first. A film or show Curatarr looks after is marked Leaving Soon instead of deleted: its poster counts down, playing it or Keep in Curatarr saves it, and at the end of the notice period Curatarr deletes it through Radarr or Sonarr. Deleting it again deletes it now. Episodes, seasons and anything Curatarr doesn't know are deleted by Jellyfin as usual.

As this Jellyfin server reaches it.
From Curatarr's Settings → Integrations (the token the Webhook plugin sends).
Untick to have Jellyfin delete files itself again.
Otherwise Jellyfin deletes the files itself while Curatarr is down.
Jellyfin plays the default audio track and the first copy, whatever the device can decode. With this, a browser plays the stereo AAC track Curatarr adds instead of having AC3 converted, and of two copies of a film each device gets the one it plays directly. A track or copy picked by hand is left alone.
Curatarr's custom posters for one account: that account sees them in every app, and everyone else sees the usual poster.
Beside Delete, which then deletes straight away in the web app. Needs the File Transformation plugin; takes effect when Jellyfin restarts. Other apps can't be given menu items: there, Delete marks a title Leaving Soon and deleting it again deletes it.
